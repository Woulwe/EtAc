# APK → EXE Converter

Готовый сайт + Node.js сервер.

## Запуск
npm install
npm start

Откройте http://localhost:3000

## Railway
Проект содержит Dockerfile и railway.json.

## Ограничение
APK нельзя универсально превратить в нативный Windows EXE без Android runtime/совместимости. Сервис создаёт Windows-пакет с APK и launcher.
